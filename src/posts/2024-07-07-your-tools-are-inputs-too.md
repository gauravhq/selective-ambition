---
title: Your Tools Are Inputs Too
date: 2024-07-07
pageDescription: "The very tools meant to make work easier can quietly add up to exhausting overload."
---
Content is not the only thing entering your head all day. The tools you use to get work done are inputs too, and nobody counts them that way.

There is the project manager. The analytics dashboard you check because the number might have moved. The note app. Email. Two messaging platforms, because one was never quite enough. A calendar. A task tracker. And, if you are anything like me, a second to-do list you started because the first one stopped working and you never got around to closing it.

Each one of these promised to make something easier, and in a narrow sense, each one did. That part is true. But together they created something nobody actually promised you when you signed up for any single one of them.

I counted my own tools once. Eight separate professional platforms, checked at least once a day, each with its own small red dot demanding a look. Adding it up honestly, I was spending more time moving between those contexts than I was spending inside any one of them, doing the actual work I opened the laptop for in the first place.
