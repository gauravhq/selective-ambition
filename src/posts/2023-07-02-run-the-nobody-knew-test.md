---
title: Run the Nobody-Knew Test on Your List
date: 2023-07-02
pageDescription: "A weekly question that separates real hunger from wanting to be seen doing something."
---
This one is best when your to-do list feels heavy and you cannot quite say why. Nothing on it looks unreasonable. It is just heavy.

Once a week, go through it item by item and ask the same question of each one: would I still want this if nobody ever knew I did it? No screenshots, no mention at dinner, no line on a resume. Just the task, done in total silence.

If the answer is no, that item is probably a borrowed desire, something you want for how it looks rather than how it feels to actually do it. If the answer is yes, it might be real hunger, the kind worth keeping on the list even when it is hard.

This is not a foolproof test. Some things you would still want in silence are still not worth your time this season. But it cuts through a lot of noise fast. "I ran this test on my own list and crossed off three things in ten seconds. Turns out I wanted the applause, not the work." Run the sweep weekly and watch which items survive the silence.
